# AutoIPA

AutoIPA is a tool that makes phonetic transcription simple.
- Check it out at [autoipa.org](https://www.autoipa.org).
- Read the ENIAC 2025 paper at [AutoIPA: development of an online platform to facilitate the use of automated phonetic transcription using Artificial Intelligence](https://sol.sbc.org.br/index.php/eniac/article/view/38819/38592).
